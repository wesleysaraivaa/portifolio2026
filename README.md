# Portfólio — Wesley Saraiva

Repositório do meu portfólio pessoal. O site foi construído com foco em design escuro minimalista, microinterações e alta performance para apresentar projetos reais, serviços e minha trajetória técnica.

---

## Tecnologias

- **React 19** + **TypeScript**
- **Vite**
- **Tailwind CSS v4**
- **Framer Motion** (animações e transições de tela)
- **Three.js** (efeito visual interativo no background da Hero)
- **Lucide Icons**

---

## Estrutura e Seções do Site

O site é organizado em uma experiência de página única (*single-page*), dividida nas seguintes seções:

- **Hero**: Apresentação inicial com título de impacto, chamada para contato e um fundo dinâmico renderizado em Three.js.
- **Tech Marquee**: Faixa com efeito de rolagem contínua destacando as principais ferramentas e linguagens do ecossistema.
- **Sobre Mim & Habilidades**: Resumo da minha atuação profissional, stack de tecnologias que domino e princípios de código limpo e acessibilidade.
- **Serviços**: Os tipos de soluções que desenvolvo, cobrindo landing pages de alta conversão, sites institucionais e desenvolvimento de interfaces web sob medida.
- **Projetos**: Vitrine dos trabalhos desenvolvidos. Os cards simulam a interface de uma janela de navegador, contam com sistema de filtros por categoria (sites, sistemas, estudos) e trazem links diretos para a aplicação no ar e o repositório no GitHub.
- **Processo de Trabalho & Diferenciais**: Explicação de como atuo em cada etapa do projeto — desde o entendimento da demanda e prototipagem até o desenvolvimento, otimização e entrega final.
- **Linha do Tempo & Formação**: Histórico de marcos na carreira, cursos e base educacional.
- **Disponibilidade & Contato**: Indicador em tempo real sobre agenda para novos projetos (freelance / contratação) e formulário integrado para contato rápido.
